# ARCHITECTURE CHANGE WORKFLOW

Architecture changes require extra care.

1. Identify why the current architecture is insufficient.
2. Identify gameplay systems depending on it.
3. Review existing decisions.
4. Define migration strategy.
5. Estimate Rift Score.
6. Preserve gameplay contracts.
7. Implement in reversible stages where possible.
8. Validate multiplayer and persistence.
9. Record the architectural decision.
10. Update current-state context.
