# NEW FEATURE WORKFLOW

1. Read .ao-guardian/context and existing decisions.
2. Inspect related implementation.
3. Identify the AO gameplay principle.
4. Define the player problem.
5. Define interactions with existing systems.
6. Estimate Rift Score.
7. If high-risk, stop for approval.
8. Implement the smallest coherent version.
9. Validate behavior and regressions.
10. Write a change record.
11. Update parity/context.
12. Report.
