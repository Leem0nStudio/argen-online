# MODIFY SYSTEM WORKFLOW

1. Read the system context.
2. Inspect all direct callers/dependents.
3. Identify current behavior.
4. Identify intended behavior.
5. Identify historical/reference constraints.
6. Identify invariants.
7. Estimate Rift Score.
8. Plan migration if contracts change.
9. Implement.
10. Validate dependent systems.
11. Record the change.
12. Update current-state documentation.
