# ENGAGEMENT MODEL

The project should reproduce the systemic reasons the reference game could keep
players engaged, not use manipulative engagement mechanics.

Core loop:

PREPARE
→ LEAVE SAFETY
→ EXPLORE / GATHER / HUNT / TRADE
→ RISK
→ DECIDE
→ REWARD
→ RETURN / RECOVER / INVEST
→ PROGRESS
→ PURSUE HARDER OBJECTIVE

Supporting forces:

- progression
- scarcity
- risk
- loss
- social dependence
- conflict
- discovery
- specialization
- reputation
- economy
- persistence

A new feature should reinforce at least one of these without destroying another.
