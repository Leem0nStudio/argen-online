# ZERO ASSETS

Procedural-first development has zero dependency on externally authored PNG,
sprite-sheet, texture or prerecorded sound assets.

Preferred representations:

- generated geometry
- generated materials
- shader patterns
- particles
- procedural VFX
- procedural UI primitives
- generated/synthesized sound
- code-driven animation

If external assets are later authorized, treat that as a project decision rather
than assuming it is allowed.
