# GAME IDENTITY

The project is a modern web MMORPG with Argentum Online as the gameplay
reference target.

Identity is defined by systems and player experience, not by reproducing the
historical rendering technology.

Important qualities:

- meaningful character progression
- class and character identity
- exploration
- dangerous spaces
- meaningful risk
- meaningful rewards
- player economy
- social interdependence
- PvP/PvE tension
- player-driven stories
- persistent character identity
- valuable possessions
- freedom of action

Do not equate "modern MMORPG" with the target identity.
