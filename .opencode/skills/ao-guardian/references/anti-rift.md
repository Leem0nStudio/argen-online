# ANTI-RIFT

Rift means drift away from the intended game identity.

Common drift patterns:

1. Generic MMORPG feature accumulation.
2. Modern mechanics replacing older meaningful systems.
3. Removing risk to increase convenience.
4. Removing scarcity to increase reward frequency.
5. Automating player decisions.
6. Turning social systems into NPC substitutes.
7. Replacing player economy with account progression.
8. Adding systems because competitors have them.
9. Treating current code as permanent game design.
10. Optimizing engagement metrics at the expense of identity.

The agent must identify these patterns proactively.
