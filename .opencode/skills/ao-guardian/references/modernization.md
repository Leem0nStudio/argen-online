# MODERNIZATION POLICY

Allowed modernization areas:

- rendering
- 3D-capable spatial representation
- shaders
- lighting
- VFX
- procedural materials
- procedural audio
- networking
- server authority
- prediction/reconciliation
- persistence
- streaming
- scalability
- accessibility
- responsive/mobile UX
- diagnostics
- testing
- developer tooling

A modernization must not silently redefine core gameplay.

Modern technology should remove technical limitations, not remove meaningful
player decisions.
