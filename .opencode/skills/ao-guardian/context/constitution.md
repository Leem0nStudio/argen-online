# PROJECT CONSTITUTION

This project is a modern web MMORPG strongly inspired by Argentum Online.

## Non-negotiables

1. Preserve the intended AO gameplay identity.
2. Modernize implementation, not identity, unless explicitly approved.
3. Use procedural content as the default production strategy.
4. Avoid external PNG/image/sound dependencies during procedural-first development.
5. A 2D gameplay experience may use a 3D-capable world/rendering foundation.
6. Significant changes must receive a Rift Score.
7. Significant changes must be recorded in context.
8. Existing code is not automatically the game-design authority.
9. Never invent historical AO rules and label them as verified.
10. Prefer player agency, meaningful risk/reward, social interdependence,
   exploration, scarcity and persistent character identity.

## Approval

Rift Score >= 71 requires explicit user approval before implementation.
